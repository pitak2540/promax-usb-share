# JAMES USB Share

แชร์อุปกรณ์ USB ที่เสียบ **มือถือ Android (ผ่านสาย OTG)** ไปให้ **คอม Windows** ใช้ผ่าน Wi-Fi วงเดียวกัน
Windows จะเห็นอุปกรณ์ใน Device Manager เหมือนเสียบตรงที่คอม โปรแกรมเดิม (เช่น EcuFlash, โปรแกรม J2534, โปรแกรมอ่าน EEPROM) จึงใช้ได้เหมือนเดิม

```
[อุปกรณ์ USB] --OTG--> [มือถือ Android: แอพ JAMES USB Share = USB/IP server :3240]
                                   |  Wi-Fi (USB/IP v1.1.1)
                                   v
              [คอม Windows: usbip-win2 (ไดรเวอร์ Microsoft รับรอง) + โปรแกรม JamesUsbShare.exe]
```

## สิ่งที่อยู่ในโปรเจกต์

| โฟลเดอร์ | คืออะไร |
|---|---|
| `common/` | โค้ดโปรโตคอล USB/IP (ใช้ร่วมกันทั้งแอพและโปรแกรม) + ชุดทดสอบ |
| `android/` | แอพ Android (APK) — เป็นเซิร์ฟเวอร์ USB/IP, foreground service, Wi-Fi low-latency lock, ประกาศตัวเองให้คอมหาเจอ |
| `desktop/` | โปรแกรม Windows (.exe) — หาเครื่องมือถืออัตโนมัติ, แสดงรายการอุปกรณ์, กดเชื่อมต่อ/ตัดการเชื่อมต่อ (สั่งงาน `usbip.exe` ของ usbip-win2) |

ไฟล์ APK และ EXE สร้างอัตโนมัติด้วย GitHub Actions ทุกครั้งที่ push ไป `main` — ดาวน์โหลดได้ที่หน้า **Releases**

## วิธีติดตั้ง

**บนคอม Windows 10/11 (64-bit)**
1. ติดตั้ง **usbip-win2** จาก https://github.com/vadimgrn/usbip-win2/releases (ไฟล์ `USBip-x.x.x.x-x64.exe`) แล้วรีสตาร์ทเครื่อง
   - แนะนำเวอร์ชัน 0.9.7.7 ขึ้นไป **ห้ามใช้ 0.9.7.8** (มีบั๊กจอฟ้า)
2. แตกไฟล์ `JamesUsbShare-Windows.zip` แล้วเปิด `JamesUsbShare.exe`
3. ถ้า Windows Firewall ถาม ให้กด **Allow** (เพื่อให้หามือถือเจออัตโนมัติ)

**บนมือถือ Android 9 ขึ้นไป**
1. ติดตั้ง `JamesUsbShare.apk` (อนุญาตการติดตั้งจากแหล่งที่ไม่รู้จัก)
2. เปิดแอพ → กดปุ่ม **เริ่มแชร์** (แอพจะไม่แชร์เองตอนเปิด) แล้วจะเห็น IP ของมือถือ
3. กด "ปิดการประหยัดแบตให้แอพนี้" หนึ่งครั้ง
4. เสียบอุปกรณ์ผ่านสาย OTG (ถ้าอุปกรณ์กินไฟมาก เช่น CH341A หรือแฟลชไดรฟ์ ให้ใช้ OTG hub ที่มีไฟเลี้ยง)

## วิธีใช้
1. ให้มือถือกับคอมอยู่ Wi-Fi วงเดียวกัน (แนะนำ 5 GHz)
2. ในโปรแกรมบนคอม เลือกมือถือทางซ้าย (ถ้าไม่ขึ้น พิมพ์ IP ที่เห็นในแอพแล้วกด "เพิ่ม IP")
3. เลือกอุปกรณ์ → กด **เชื่อมต่อเข้าคอม** → ถ้ามือถือถามสิทธิ์ USB ให้กด **ตกลง**
4. อุปกรณ์จะโผล่ใน Device Manager — ถ้าเป็นครั้งแรก Windows จะลงไดรเวอร์ของอุปกรณ์นั้นตามปกติ (เช่นไดรเวอร์ Tactrix, FTDI, CH340)
5. เลิกใช้: เลือกในตารางล่าง → **ตัดการเชื่อมต่อ**

เปิดหน้าจอมือถือค้างไว้ระหว่างใช้งาน (ติ๊กไว้ในแอพแล้วเป็นค่าเริ่มต้น) — Android จะเปิดโหมด Wi-Fi หน่วงต่ำได้เฉพาะตอนจอเปิดและแอพอยู่หน้าจอ ถ้าจอดับ ความหน่วงจะกระโดดเป็นหลายร้อยมิลลิวินาที

## ใช้ข้ามเครือข่าย (มือถือใช้เน็ตมือถือ / อยู่คนละที่กับคอม)

ทำได้ในแอพเราเลย ไม่ต้องลงแอพอื่น

**รหัสจับคู่**
1. ในแอพมือถือกด **เริ่มแชร์** จะเห็นรหัสจับคู่ 8 ตัว (สวิตช์ 'ให้คอมเชื่อมต่อจากที่อื่นได้' เปิดไว้เป็นค่าเริ่มต้น)
2. ในโปรแกรมบนคอมกด **เพิ่มมือถือด้วยรหัสจับคู่** แล้วพิมพ์รหัสนั้น (โปรแกรมจำรหัสไว้ให้ ครั้งต่อไปไม่ต้องพิมพ์ใหม่)
3. ต้องเปิดโปรแกรมบนคอมค้างไว้ระหว่างใช้งาน เพราะข้อมูลวิ่งผ่านโปรแกรม
4. ใครมีรหัสก็เชื่อมต่อได้ — อย่าแชร์รหัส และกด "เปลี่ยนรหัส" ในแอพได้ทุกเมื่อ

Relay เป็น Cloudflare Worker ของคุณเอง (โฟลเดอร์ `relay/`) deploy อัตโนมัติด้วย GitHub Actions เมื่อใส่ secret `CLOUDFLARE_API_TOKEN` ใน repo (สร้าง token จากเทมเพลต "Edit Cloudflare Workers") ฟรีในระดับใช้งานทั่วไป

ข้ามเครือข่ายจะหน่วงกว่า Wi-Fi วงเดียวกัน — อ่าน/ลบโค้ดได้ แต่ถ้าโปรแกรมสแกนขึ้น timeout ให้ลองใหม่

## ⚠ Tactrix OpenPort 2.0
- ใช้ผ่าน Wi-Fi ได้: อ่าน/ลบโค้ด, ดูค่าสด, ล็อกข้อมูล
- **ห้ามแฟลช/เขียน ECU ผ่าน Wi-Fi** — ถ้าสัญญาณสะดุดกลางคัน J2534 จะ timeout และกล่อง ECU อาจเสียจนสตาร์ทไม่ติด เวลาแฟลชให้เสียบสาย USB ตรงเข้าคอมเท่านั้น
- ยังไม่มีใครยืนยันต่อสาธารณะว่า OpenPort ทำงานผ่าน USB/IP ได้ ให้ทดสอบการอ่านค่าก่อนใช้งานจริง

## ข้อจำกัด
- อุปกรณ์ประเภท isochronous (เว็บแคม, การ์ดเสียง USB, ไมค์ USB) ใช้ไม่ได้ เพราะ Android ไม่มี API ให้
- USB hub แชร์ทั้งตัวไม่ได้ แต่อุปกรณ์ที่เสียบอยู่หลัง hub จะแสดงแยกเป็นรายชิ้นและแชร์ได้
- แฟลชไดรฟ์: เมื่อแชร์ Android จะถอดการเมานต์ออกจากมือถือ และความเร็วผ่าน Wi-Fi จะช้า
- อุปกรณ์หนึ่งชิ้นใช้ได้ทีละคอมเครื่องเดียว

## หมายเหตุด้านเทคนิค
- โปรโตคอล: USB/IP v1.1.1 (Linux `Documentation/usb/usbip_protocol.rst`), TCP 3240, big-endian, header URB 48 ไบต์
- การค้นหาเครื่อง: มือถือ broadcast UDP พอร์ต 3241 ทุก 2 วินาที
- Bulk/Interrupt ใช้ `UsbRequest` แบบ asynchronous (คิวได้หลาย URB พร้อมกัน, ยกเลิกได้จริงเมื่อ Windows ส่ง UNLINK); Control transfer ทำทีละคำสั่งบนเธรดแยก; SET_CONFIGURATION / SET_INTERFACE ถูกแปลงเป็น API ของ Android
- ไฟล์ `android/app/jamesusbshare.keystore` คือกุญแจเซ็น APK (เพื่อให้อัปเดตทับเวอร์ชันเก่าได้) — เก็บ repo นี้เป็น private
